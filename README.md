# Dice Game App

## Project Description
A simple Flutter dice game where the player rolls two dice and the app displays their total.

## Features
- Roll two dice with random values from 1 to 6.
- Display the total of both dice.
- Show a happy image when the total is 10 or more, and a sad image otherwise.
- Reset both dice to 1 and the total to 2.
- Dark theme and styled buttons.

## Technologies Used
- Flutter
- Dart

## Project Structure
- `lib/main.dart`: Main application and game logic.
- `lib/dice.dart`: Reusable Dice widget.
- `assets/happy.png`: Happy image.
- `assets/sad.png`: Sad image.
- `pubspec.yaml`: Project configuration and asset registration.

## How to Run
1. Install Flutter and set up an editor.
2. Open the project folder.
3. Run `flutter pub get`.
4. Run `flutter run`.
